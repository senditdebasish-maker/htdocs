# User Guide

## Tender lifecycle

1. Create or select a financial year.
2. Configure Panchayat settings, schemes, funds and budget allocations.
3. Create an annual procurement plan, then convert it to a project/work or tender when ready.
4. Create a tender linked to the project.
5. Add approvals, sanctions, schedule, estimated value and BOQ.
6. Run the compliance check.
7. Submit the tender for approval workflow.
8. Generate NIT/tender document/BOQ PDF drafts as required.
9. Publish by recording official/manual publication references.
10. Start and close bidding.
11. Add bidders.
12. Record technical opening and evaluation criteria.
13. Finalise technical evaluation and generate the technical evaluation PDF if required.
14. Record financial bids for technically qualified bidders.
15. Compute rankings, comparative statement and comparative PDF.
16. Recommend and approve award.
17. Issue LOA, record agreement and issue work order.
18. Record progress, measurements, bills and payment records.
19. Generate bill records and advance completion steps.
20. Generate completion certificate and complete tender-file index drafts.

## Compliance results

- **BLOCKING** failures stop submission/publication where enforced.
- **WARNING** indicates configured system concerns.
- **VERIFICATION REQUIRED** means the system cannot verify the rule automatically. It must be checked manually against current authority instructions. It is not a legal-compliance claim.

## Documents

Generated documents are PDF drafts in the Document register. Current generators include NIT, tender document, BOQ, technical evaluation, comparative statement, LOA, agreement, work order, bill record, completion certificate and complete tender-file index. Supporting documents can be uploaded and attached to tender/project/bill/etc. Uploads are checked for allowed extensions and unsafe content types.

Public users can view only published tender information and public NIT PDFs. Internal documents require login and permission.

## Payments

Payments are records of manual/offline payment references. The system does not send money, connect to banks or claim bank execution.

## Reports

Reports are generated from live database records. The tender register can be exported as CSV or PDF; reconciliation/status reports are available from the Reports menu according to your role permissions.
